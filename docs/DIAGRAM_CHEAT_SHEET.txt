║                    EXPORT FORMATS - WHICH TO USE?                             ║
╚════════════════════════════════════════════════════════════════════════════════╝

PNG:
  ✓ Use if:    General use, easy to share, web-friendly
  ✓ Size:      Medium (good balance)
  ✓ Quality:   Good for screen viewing
  ✗ Printing:  Okay, but SVG is better
  
  👉 Download in: Mermaid Live → "Download PNG"

SVG:
  ✓ Use if:    Printing thesis, professional quality, scalable
  ✓ Size:      Larger file
  ✓ Quality:   Excellent (vector, no pixelation)
  ✓ Printing:  Perfect for printed thesis
  
  👉 Download in: Mermaid Live → "Download SVG"

PDF:
  ✓ Use if:    Final thesis format, professional document
  ✗ Limitation: Mermaid Live doesn't directly export to PDF
  
  👉 Workaround: Export SVG → Convert to PDF using online tool
                 or Insert SVG/PNG into Word then Export as PDF

Copy Image:
  ✓ Use if:    Quick paste into Google Docs/Word
  ✓ Steps:     Right-click diagram → Copy Image → Paste directly
  
  👉 Do in: Mermaid Live website

║                         TROUBLESHOOTING                                        ║
╚════════════════════════════════════════════════════════════════════════════════╝

PROBLEM: Mermaid Live won't render diagram
FIX: 
  1. Refresh page (Ctrl+R)
  2. Copy code again (exactly as shown)
  3. Clear editor, paste again
  4. Try different browser (Chrome, Firefox)

PROBLEM: "Cannot download PNG"
FIX:
  1. Try "Download SVG" instead
  2. Try "Copy image" → paste into Word
  3. Screenshot the diagram directly

PROBLEM: Diagram too small/hard to read
FIX:
  1. In Mermaid Live, use zoom (usually bottom right)
  2. Download larger resolution
  3. Use SVG (higher quality) instead of PNG

PROBLEM: ChatGPT gives error
FIX:
  1. Copy prompt exactly as shown
  2. If ChatGPT errors, ask: "Fix any syntax errors"
  3. Try again

PROBLEM: Missing some entities
FIX:
  1. Verify you copied entire code block
  2. Check for copy-paste errors
  3. Use ER_Diagram_Mermaid_Ready.md file directly
