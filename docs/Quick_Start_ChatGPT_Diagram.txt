STEP 1: Copy the Full Prompt
─────────────────────────────────────────────────────────────────────────────────
Location: docs/ChatGPT_Prompt_ER_Diagram.md
(Find the section: "Full Prompt to Copy-Paste into ChatGPT")

Copy everything from: "You are an expert database architect..."
To: "...NOW GENERATE THE COMPLETE MERMAID ER DIAGRAM CODE:"


STEP 2: Paste into ChatGPT & Generate
─────────────────────────────────────────────────────────────────────────────────
1. Go to: https://chat.openai.com
2. Click: "+ New Chat" (or use existing chat)
3. Paste: The entire prompt (Ctrl+V)
4. Send: Press Enter/Send button
5. Wait: ChatGPT generates the Mermaid code (takes 10-30 seconds)


STEP 3: Copy Output & Render
─────────────────────────────────────────────────────────────────────────────────
ChatGPT will give you code in this format:

    ```mermaid
    erDiagram
        USER {
            ...
        }
        ...
    ```

Copy the ENTIRE code block (including ``` markers)


STEP 4: Render in Mermaid Live Editor
─────────────────────────────────────────────────────────────────────────────────
1. Go to: https://mermaid.live
2. Paste: The mermaid code in the left panel
3. View: Diagram renders on the right side
4. Export: Click "Download SVG" or "Download PNG"
5. Save: Save to your computer


STEP 5: Use in Your Thesis
─────────────────────────────────────────────────────────────────────────────────
✓ Option A: Insert PNG/SVG into Word/Google Docs
✓ Option B: Paste into markdown file
✓ Option C: Screenshot the rendered diagram

COMMON ISSUES & FIXES:
─────────────────────────────────────────────────────────────────────────────────

❌ "ChatGPT gives plain text, not Mermaid code"
✓ Ask ChatGPT: "Format this as Mermaid erDiagram code in code block"

❌ "Mermaid Live shows error"
✓ Usually syntax error - ask ChatGPT: "Fix any syntax errors in this Mermaid code"

❌ "Diagram too messy/hard to read"
✓ Ask ChatGPT: "Reorganize the diagram with better layout grouping entities by type"

❌ "Colors not showing"
✓ Mermaid erDiagram doesn't support custom colors - use grayscale and add legend

❌ "Missing some entities"
✓ Ask ChatGPT: "Add all 24 entities including COUPON, PROMOTION, NOTIFICATION, etc."
