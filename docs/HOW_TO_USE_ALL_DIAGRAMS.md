## 📸 Export to Image (For Thesis)

### **From Mermaid Live to PNG**
1. Go to https://mermaid.live
2. Paste mermaid code
3. Click **"Download PNG"**
4. Save to your computer
5. Insert into Word/Google Docs/PDF

### **From Mermaid Live to SVG**
1. Same as above
2. Click **"Download SVG"** instead
3. SVG is higher quality, good for printing

### **From Mermaid Live to Copy Image**
1. Right-click diagram
2. Select "Copy Image"
3. Paste directly into Word/Google Docs
