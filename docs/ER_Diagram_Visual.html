📋 Legend

PK - Primary Key
FK - Foreign Key
1:N - One to Many
N:1 - Many to One
UUID - Universally Unique Identifier

🔑 Key Relationships

  • User can have multiple Carts, Wishlists, and Orders (1:N relationships)
  • Cart & Wishlist support guest users via session_id (nullable user_id)
  • Cart & Wishlist contain multiple items referencing Products (1:N → N:1)
  • Product belongs to one Category and one Brand (N:1 relationships)
  • Product can have multiple Variants (size, color, etc.) - optional (1:N)
  • Category supports hierarchical structure via self-referencing parent_id
  • Coupon can be applied to Cart for discount calculation
  • Order captures cart snapshot at checkout time with status tracking

💡 Design Features

  • Guest Support: Cart and Wishlist use nullable user_id + session_id for unauthenticated users
  • Flexible Pricing: Regular price, sale_price, and cost_price for comprehensive pricing management
  • Inventory Tracking: Stock quantity management with min_stock_alert thresholds
  • SEO Optimization: Meta fields (meta_title, meta_description) for products, categories, and brands
  • Extensibility: Metadata fields (JSON) for custom data without schema changes
  • Product Variants: Support for variations (size, color, material, etc.) via optional variant_id
  • Status Tracking: Boolean flags (is_active, is_featured, is_public) for feature control
  • Order Snapshots: Order items store product details at purchase time (price freeze)
  • Hierarchical Categories: Self-referencing parent_id enables multi-level category trees

🔗 API Endpoints Mapping

✅ Working Endpoints

  • /api/v1/auth/login → User authentication (JWT token)
  • /api/v1/auth/register → User registration
  • /api/v1/products → Product catalog with Category & Brand (18 products)
  • /api/v1/products/{id} → Single product details
  • /api/v1/master/categories → Category hierarchy
  • /api/v1/master/brands → Brand listings
  • /api/v1/orders → Order history (empty currently)
  • /api/v1/orders/{id} → Order details

⏳ Pending Implementation (404)

  • /api/v1/cart → Get/Update cart
  • /api/v1/cart/items → Add/Update/Delete cart items
  • /api/v1/cart/checkout → Convert cart to order
  • /api/v1/wishlist → Get/Update wishlist
  • /api/v1/wishlist/items → Add/Delete wishlist items
  • /api/v1/wishlist/check → Check product in wishlist
  • /api/v1/coupons/apply → Validate and apply coupon

🔧 Current Workarounds
